# TimeAnnouncer 1.0 Release Notes

TimeAnnouncer is a macOS menu bar app that speaks the current time at a chosen interval. It is designed for lightweight time awareness without opening a window.

## Highlights

- Menu bar only: TimeAnnouncer stays out of the Dock and runs from the menu bar.
- Safe first run: new installs start paused and use the built-in macOS System Voice.
- Quick audio check: **Preview Voice** lets you confirm output before enabling announcements.
- Flexible timing: choose clock-aligned intervals such as `:00`, `:15`, `:30`, and `:45`, or use fixed-interval timing.
- Voice choices: System Voice works without setup, Kokoro 82M supports local higher-quality speech, and ElevenLabs supports optional cloud speech with a saved API key.
- Launch at login: optional startup behavior is available from the menu.

## Install

1. Download `TimeAnnouncer.dmg`.
2. Open the disk image.
3. Drag `TimeAnnouncer.app` into Applications.
4. Open TimeAnnouncer from Applications.
5. Use the menu bar clock icon to preview the voice and resume announcements.

## System Requirements

- macOS 13 or later.
- Optional Kokoro voice setup requires running `./scripts/setup-kokoro.sh` from the project checkout.
- Optional ElevenLabs voice requires an ElevenLabs API key.

## Privacy

TimeAnnouncer stores preferences locally. System Voice and Kokoro speech stay on the Mac. ElevenLabs is only used if selected, and then the app sends the phrase being spoken to ElevenLabs to generate audio.
