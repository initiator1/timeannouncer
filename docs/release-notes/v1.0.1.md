# Time Announcer 1.0.1

A maintenance release that fixes a real problem in 1.0.0: the Kokoro voice
could not be set up by anyone who installed from the DMG.

## Fixed

- **Kokoro voice setup now works from the installed app.** In 1.0.0 the setup
  dialog pointed at a script that was not included in the download, so two of
  the three listed voices could not be used. The setup script now ships inside
  the app, and the dialog offers a **Copy Command** button.
- **The setup dialog says what it will cost** before you start — it needs
  Homebrew, downloads about 2 GB, and takes a few minutes.
- **Now a universal build.** 1.0.0 was Apple-silicon only despite listing
  macOS 13 as the requirement, so Intel Macs could download an app that would
  not run.
- **New app icon** is included. It was redesigned after 1.0.0 was built and
  never made it into the download.
- **Check for Updates…** has been added to the menu. 1.0.0 had no way to learn
  that a newer version existed.
- **Version numbers report correctly.** 1.0.0 hardcoded its version, so any
  later build would still have identified itself as 1.0.

## Requirements

- macOS 13 or later
- Apple silicon or Intel
