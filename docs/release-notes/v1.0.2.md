# Time Announcer 1.0.2

Release candidate. Public distribution remains pending.

Hear the time without checking a screen. This update improves voice recovery,
settings feedback, and the reliability of the download package.

## Changes

- Local voice requests have a deadline. A stuck worker falls back to System Voice
  and can recover on the next request.
- Changing voices or pausing cancels pending speech. Quitting stops the local worker.
- Reopening the app from Applications or Spotlight opens its existing menu.
- The menu shows when a voice is preparing or when System Voice handles a failure.
- Failed audio playback retains the phrase you requested.
- Invalid custom intervals and empty API keys show a recovery message.
- Launch at Login reflects macOS registration and approval status.
- The app includes a privacy manifest for its local preferences.
- Release checks reject stale packages and preserve the previous package for recovery.

## Requirements and limits

macOS 13 or later. The package includes Apple silicon and Intel binaries.
The current acceptance run uses Apple silicon on macOS 27.0.1. Intel and macOS 13
execution remain untested for this candidate.

System Voice works without an account. Kokoro needs a separate local setup.
ElevenLabs needs your API key and can use paid credits. This release does not
include an automatic updater. Use Check for Updates to open the download page.

To update, quit Time Announcer and replace the app in Applications. Preferences
and any saved Keychain API key remain in place.
